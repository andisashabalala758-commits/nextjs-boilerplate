
# Creche Website

A modern, mobile-friendly website created to help a local creche establish a professional online presence and make it easier for parents to discover the school and get in touch.

## About the Project

This website was developed as a demo concept for a local creche. It presents important information about the school in a simple and accessible way.

The goal is to help the creche:
- Build a professional online presence
- Introduce its programmes and services
- Share information with parents
- Make contact easier through online communication

## Features

- Responsive design for mobile phones, tablets and computers
- Creche information and introduction
- Programmes and activities
- Photo gallery
- Contact information
- WhatsApp contact option
- Location and map

## Technologies Used

- HTML
- CSS
- JavaScript
